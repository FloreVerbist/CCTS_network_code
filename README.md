# CCTS_network_code
This repository contains all scripts (julia programming language), preprocessed input files and some figures and output files, related to the paper entitled
"Assessing CO2 Value Chain Participation under Negative Emission Pricing and EU Industry Relocation". 

The input files are generated using the "preprocessing_code.jl" file based on AIDRES-EU data.
The folder "Ev2" allows to regenerate the used environment.
